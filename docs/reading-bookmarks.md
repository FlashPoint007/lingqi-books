# 阅读书签 / Reading bookmarks

阅读器右上角的“书签”可保存当前章节和位置，并附上最多 500 字备注。点击书签回到对应章节；移除后可撤销。来源章节失效或未加载时，不会跳转到错误章节。

Bookmarks in the reader save the current chapter and position with an optional note (up to 500 characters). Select a bookmark to return to it; removing one can be undone. Unavailable chapters do not silently redirect elsewhere.

数据仅保存在当前浏览器，不上传服务器。书架版本 2 JSON 备份现包含书签，旧版没有书签的备份仍可恢复。恢复为合并，不清空既有数据；备注以纯文本显示。备份仍不包含本地 TXT 正文或阅读设置。更换阅读源不会跨作品自动迁移书签。

Data stays in this browser and is not uploaded. Version 2 library backups now include bookmarks, while older backups remain compatible. Restore merges records without clearing existing data; notes render as plain text. Local TXT bodies and reading preferences remain excluded. Switching sources does not automatically transfer bookmarks between works.
